Flow of Student Creation
App -> LoadAllMenus -> Store them all inside MenuRepo -> getMenu('Menu Name') -> InputHandlerCalled -> takesInput by calling specific function getInputforMainMenu -> calls specific Validator Functions on input based on the menu -> throws specific error if invalid input -> else returns input -> in case of error app catches error and gracefully restart asking input-> else for correct valid input app sends it to the RoutesToMenuMapper and gets a specific route to be hitted -> SystemController will be called as controller.hit(panle route we got) -> this hit function returns specific menu route which is to be opened -> app calls getMenu('Menu Name') -> suppose we selected student i.e 'Main:student:panel' -> again input handler takes input and validator validates based on the menu provided -> the input of this menu is used to get the route which is to be called from RoutesToMenuMapper -> we again get specific route which is tto be called -> System controller again calls hit and this time suppose we hit this route 'Student:signup' -> system controller will have all other controllers composed inside it. the name Student here will tell it the controller to be called and signup will tell it which function of this controller is to be called. on calling it the student controller will return the register form -> system controller us register form ka refernce store ker k form.pull ka function call karay gi. -> ye function input handler ka use ker k details get karay ga. -> details ki array return karay-> system controller register ka function call keray ga usay ye inputs day ga and then success bool wapis say app ko return ker day ga. -> app k pass aik contextStore ka auto obj ho ga jis may wo role signed in ho ga -> us ko null na patay hoau app usay kabhi bhi main menu dikhaye ga hi nahi
